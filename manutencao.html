1 Mensagem Personalizada

📌 Enunciado:

Modifique a variável mensagem para exibir: "Bem-vindo(a) ao JavaScript!"

✏️ Modifique: a variável mensagem dentro do JavaScript.
🎨 DESAFIO EXTRA: Altere a cor de fundo da página e a cor do texto da mensagem no CSS.
📄 atividade1.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mensagem Personalizada</title> <style> /* ESTILOS */ body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; height: 100vh; background: #f0f0f0; margin: 0; } .caixa { background: white; padding: 40px; border-radius: 16px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); text-align: center; max-width: 500px; } .mensagem { font-size: 1.8rem; color: #f7971e; font-weight: bold; margin-top: 10px; } h1 { color: #1a1a2e; margin-bottom: 10px; } </style> </head> <body> <div class="caixa"> <h1>📌 Mensagem</h1> <div class="mensagem" id="mensagem"></div> </div> <script> // ✏️ MODIFIQUE A VARIÁVEL ABAIXO let mensagem = "Olá, mundo!"; // Exibe a mensagem na tela document.getElementById("mensagem").textContent = mensagem; </script> </body> </html>
✅ Copiado!
2 Calculadora de Soma

📌 Enunciado:

Modifique as variáveis num1 e num2 para que a soma seja 15.

✏️ Modifique: as variáveis num1 e num2 dentro do JavaScript.
🎨 DESAFIO EXTRA: Adicione uma nova variável num3 e exiba a soma dos três números.
📄 atividade2.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Calculadora de Soma</title> <style> body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; height: 100vh; background: #f0f0f0; margin: 0; } .caixa { background: white; padding: 40px; border-radius: 16px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); text-align: center; } .numero { font-size: 1.3rem; color: #f7971e; font-weight: bold; } .resultado { font-size: 1.8rem; color: #28a745; font-weight: bold; margin-top: 10px; } h1 { color: #1a1a2e; } p { font-size: 1.1rem; color: #2c3e50; } </style> </head> <body> <div class="caixa"> <h1>🧮 Calculadora</h1> <p>Número 1: <span class="numero" id="num1"></span></p> <p>Número 2: <span class="numero" id="num2"></span></p> <div class="resultado" id="soma"></div> </div> <script> // ✏️ MODIFIQUE AS VARIÁVEIS ABAIXO let num1 = 5; let num2 = 3; let soma = num1 + num2; document.getElementById("num1").textContent = num1; document.getElementById("num2").textContent = num2; document.getElementById("soma").textContent = "Soma: " + soma; </script> </body> </html>
✅ Copiado!
3 Mudança de Cor

📌 Enunciado:

Modifique a variável cor para "blue" e veja a cor do quadrado mudar.

✏️ Modifique: a variável cor dentro do JavaScript.
🎨 DESAFIO EXTRA: Adicione um botão que, ao ser clicado, altere a cor do quadrado para uma cor aleatória.
📄 atividade3.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Mudança de Cor</title> <style> body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; height: 100vh; background: #f0f0f0; margin: 0; } .caixa { background: white; padding: 40px; border-radius: 16px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); text-align: center; } .quadrado { width: 150px; height: 150px; border-radius: 12px; margin: 20px auto; transition: all 0.3s; background: #f7971e; } .info { font-size: 1.1rem; color: #2c3e50; } .info span { font-weight: bold; color: #f7971e; } h1 { color: #1a1a2e; } </style> </head> <body> <div class="caixa"> <h1>🎨 Mudança de Cor</h1> <div class="quadrado" id="quadrado"></div> <p class="info">Cor atual: <span id="corAtual">--</span></p> </div> <script> // ✏️ MODIFIQUE A VARIÁVEL ABAIXO let cor = "orange"; document.getElementById("quadrado").style.background = cor; document.getElementById("corAtual").textContent = cor; </script> </body> </html>
✅ Copiado!
4 Nome Completo

📌 Enunciado:

Modifique as variáveis nome e sobrenome para exibir seu nome completo.

✏️ Modifique: as variáveis nome e sobrenome dentro do JavaScript.
🎨 DESAFIO EXTRA: Adicione um campo idade e exiba "Nome completo: X, Idade: Y anos".
📄 atividade4.html
<!DOCTYPE html> <html lang="pt-BR"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Nome Completo</title> <style> body { font-family: Arial, sans-serif; display: flex; justify-content: center; align-items: center; height: 100vh; background: #f0f0f0; margin: 0; } .caixa { background: white; padding: 40px; border-radius: 16px; box-shadow: 0 4px 20px rgba(0,0,0,0.1); text-align: center; } .nome { font-size: 1.8rem; color: #f7971e; font-weight: bold; margin-top: 10px; } h1 { color: #1a1a2e; } </style> </head> <body> <div class="caixa"> <h1>👤 Nome Completo</h1> <div class="nome" id="nomeCompleto"></div> </div> <script> // ✏️ MODIFIQUE AS VARIÁVEIS ABAIXO let nome = "João"; let sobrenome = "Silva"; let nomeCompleto = nome + " " + sobrenome; document.getElementById("nomeCompleto").textContent = "Nome completo: " + nomeCompleto; </script> </body> </html>
✅ Copiado!
