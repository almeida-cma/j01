1 Declarando Variáveis

📌 Enunciado:

Declare as seguintes variáveis em JavaScript:

  • Uma variável chamada nome com o valor "Ana"
  • Uma variável chamada idade com o valor 25
  • Uma variável chamada cidade com o valor "São Paulo"

Use console.log() para exibir as três variáveis.

2 Usando const e let

📌 Enunciado:

Crie as seguintes variáveis:

  • Use const para declarar PI = 3.1415
  • Use let para declarar raio = 5
  • Calcule a área do círculo: area = PI * raio * raio

Exiba o valor de area.

// Dica: estrutura básica const PI = 3.1415; let raio = 5; let area = PI * raio * raio; console.log(area);
🔗 Link útil:
✅ Saída esperada:
78.5375

4 Criando um Objeto

📌 Enunciado:

Crie um objeto chamado carro com as propriedades:

  • marca = "Toyota"

Exiba cada propriedade usando console.log().

// Dica: estrutura do objeto let carro = { marca: "Toyota", modelo: "Corolla", ano: 2022 };
