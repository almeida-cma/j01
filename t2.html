📦 O que são Variáveis?

💡 Analogia: Variáveis são como caixas onde você pode guardar coisas diferentes. Cada caixa tem um nome (identificador) e pode armazenar um valor (conteúdo).

Variáveis em JavaScript são espaços de armazenamento que permitem guardar e manipular dados de diferentes tipos. Elas funcionam como containers onde você pode colocar números, textos, listas e muito mais.

📄 exemplo-variaveis.js
// Criando uma variável (caixa) chamada "idade" let idade = 25; // Criando uma variável (caixa) chamada "nome" let nome = "João"; // Usando as variáveis console.log("Nome:", nome); console.log("Idade:", idade);
✅ Copiado!
📌 IMPORTANTE: JavaScript é Case Sensitive — diferencia letras maiúsculas e minúsculas. As variáveis nome e Nome são diferentes!

📝 Declaração de Variáveis

Em JavaScript, existem 4 maneiras de declarar variáveis:

🔴 var

var x = 10;
Escopo de função. Evitar usar em código moderno.

🔵 let

let y = 20;
Escopo de bloco. Permite reatribuição.

🟢 const

const z = 30;
Escopo de bloco. Valor não pode ser alterado.
⚠️ DICA: Use const sempre que possível, let quando precisar alterar o valor, e var apenas para suporte a navegadores antigos (pré-2015).

📌 Regra CamelCase

A regra CamelCase é uma convenção para nomear variáveis com mais de uma palavra:

📄 camelcase.js
// CamelCase: primeira palavra minúscula, as demais com maiúscula let nomeDoUsuario = "Maria"; let idadeDaPessoa = 30; let totalDeProdutos = 150; // PascalCase: todas as palavras com maiúscula (usado para classes) class Usuario { /* ... */ } console.log("Nome:", nomeDoUsuario); console.log("Idade:", idadeDaPessoa); console.log("Total:", totalDeProdutos);
✅ Copiado!
✅ BOA PRÁTICA: Sempre use nomes descritivos e intuitivos para suas variáveis. Evite nomes como a, b, x.

📊 Tipos de Dados em JavaScript

JavaScript possui 8 tipos principais de dados:

Tipo Descrição Exemplo
String Texto / Cadeia de caracteres "Olá mundo!"
Number Números inteiros ou decimais 42, 3.14
BigInt Números inteiros muito grandes 12345678901234567890n
Boolean Verdadeiro ou Falso true, false
Undefined Variável declarada sem valor let x;
Null Ausência intencional de valor let x = null;
Symbol Valor único e imutável Symbol("id")
Object Coleção de dados (chave-valor) { nome: "João", idade: 25 }

📌 Strings e Números - Exemplos

📄 strings-numeros.js
// STRINGS - Texto let saudacao = "Olá, mundo!"; let nome = 'João'; let mensagem = `Bem-vindo, ${nome}`; // NÚMEROS - Inteiros e Decimais let idade = 25; let altura = 1.75; let preco = 199.90; // CONVERSÃO: parseInt() e parseFloat() let textoNumero = "42"; let numeroInteiro = parseInt(textoNumero); // 42 let numeroDecimal = parseFloat("3.14"); // 3.14 console.log("Saudação:", saudacao); console.log("Mensagem:", mensagem); console.log("Inteiro:", numeroInteiro); console.log("Decimal:", numeroDecimal);
✅ Copiado!
💡 DICA: Use parseInt() para converter strings em números inteiros e parseFloat() para números com casas decimais.

🎯 Escopo de Variáveis

O escopo define onde uma variável é visível e pode ser acessada.

🌍 Global

Variáveis declaradas fora de qualquer função ou bloco. Acessíveis em todo o código.

let global = "Sou global";

📦 Função

Variáveis declaradas dentro de uma função. Acessíveis apenas dentro dela.

function teste() {
  let local = "Sou local";
}

🔲 Bloco

Variáveis declaradas com let ou const dentro de um bloco { }.

if (true) {
  let bloco = "Sou do bloco";
}
📄 escopo.js
// Exemplo de escopos let global = "🌍 Global"; function exemplo() { let funcao = "📦 Função"; if (true) { let bloco = "🔲 Bloco"; console.log(global); // ✅ Acessível console.log(funcao); // ✅ Acessível console.log(bloco); // ✅ Acessível } // console.log(bloco); ❌ ERRO - não acessível fora do bloco } exemplo();
✅ Copiado!

🔗 Objetos e Notação de Ponto

Objetos são estruturas que agrupam dados relacionados em pares chave-valor.

📄 objetos.js
// Criando um objeto let pessoa = { nome: "Maria", idade: 30, cidade: "São Paulo", saudacao: function() { return "Olá, " + this.nome; } }; // Acessando com NOTAÇÃO DE PONTO console.log(pessoa.nome); // "Maria" console.log(pessoa.idade); // 30 console.log(pessoa.cidade); // "São Paulo" console.log(pessoa.saudacao()); // "Olá, Maria"
✅ Copiado!
📌 NOTAÇÃO DE PONTO: Use objeto.propriedade para acessar valores e objeto.metodo() para executar funções dentro do objeto.
